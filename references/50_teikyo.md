# 50 購入後の提供と、本番の通し確認（タスク7・8）

支払いリンクを置いただけでは「売れる」状態ではない。**買った人に何をどう渡すか**を決めて作る。

## 渡し方を選ぶ（本人が選ぶ・最初は①を勧める）
| 方式 | 中身 | 要る物 |
|---|---|---|
| ① 手動で渡す | Stripe の **支払い** 一覧を本人がスマホで見て、メール／LINE で納品・予約確定 | 何も要らない。1日1回 Stripe を見る習慣 |
| ② 確認ページで渡す | 支払いリンクの「支払い後の確認ページ」にダウンロード URL や案内を書く | URL を知れば誰でも見られる物に限る |
| ③ 自動で渡す（Webhook） | Stripe → Worker に通知 → D1 の該当申込に「支払済 💳」が付く（`/admin` で見える）。渡す物の自動送信は別途作る | Stripe の署名シークレットを Cloudflare の Secrets に本人が入れる |

③は鍵を扱うので、①②で回し始めてから。

## ①の手順書（AI が本人用に `state/UNYO.md` として書く）
1. Stripe アプリ or ダッシュボード → **支払い** → 新しい支払いを見る。
2. 支払いの詳細の **Client reference ID**（＝`/admin` の申込番号 #）で申込を探し、申込のメールに決めた物を送る。番号が無い（申込せずに直接買った）時はメールで照合し、無ければ Stripe のメールに連絡する。
   - 平日◯時までに送る、と `state/UNYO.md` に書く。送信元のメール（本人の物）を決める。
3. 送ったら D1 の管理画面（`/admin`）で該当の申込を「対応済」にする。
4. 返金が要る時は Stripe の支払い詳細 → **返金**（ノーコード・公式）。

## ③に進む時（AI）
- `src/index.js` の `/api/stripe/webhook` を有効にし、`STRIPE_WEBHOOK_SECRET` を **Cloudflare の Worker → Settings → Variables and Secrets** に本人が入れる。
- ひな形に実装済み：署名検証（複数 v1・定数時間比較）・二重処理防止・`checkout.session.completed`（`payment_status=paid`）で「申込番号（client_reference_id）とメールが両方一致」した時だけ支払済に（番号なし・メール違い・金額違いは自動で支払済にしない＝管理画面で確認）。**自動で支払済みにするには、Secrets に `EXPECTED_AMOUNT`（例 3000）と `EXPECTED_CURRENCY`（例 jpy）が必須**（任意で `EXPECTED_PAYMENT_LINK`＝plink_…、`REQUIRE_LIVE`=1）。合わない支払いは管理画面の「要確認の支払い」に出る。D1 に `migrations/0002_stripe_review.sql` も入れる。返金は `charge.refunded` で取り消し表示。
- 本人が Stripe の **開発者 → Webhook** でエンドポイント `https://<公開URL>/api/stripe/webhook` を登録する。

## 本番の通し確認（タスク8・本人のスマホで）
| 順 | やる事 | 見える物 |
|---|---|---|
| 1 | 公開 URL を開く | トップが表示、フッターに特商法・利用条件・プライバシー |
| 2 | 申込フォームを送る | 「受け付けました」 |
| 3 | `/admin?key=<管理キー>` を開く | さっきの申込が一覧に出る |
| 4 | **テスト環境**の支払いリンクでテストカード 4242… で買う（30_stripe.md） | Stripe（テスト）の確認ページ → テスト環境の「支払い」に出る |
| 5 | 渡す（①なら手動） | 買った自分に届く |
| 6 | Stripe（テスト）で返金 | 返金済になる |
| 6b | 本番リンクに戻し、申込→/thanks の「お支払いへ」を**押すだけ**（買わない） | 本番の Checkout 画面が開き、引渡時期と取消条件が見える |
| 7 | `/admin` で「対応済」にする | 状態が変わる |

全部通ったら `state/PROGRESS.md` のタスク8 を完了にし、日付を書く。あわせて：申込を2回連打しても1件になる・`/admin` を鍵なしで開くと 403・スマホで3ページが崩れない、を見る。

## 管理画面の鍵（`ADMIN_KEY`）
- `/admin` は `ADMIN_KEY` が無いと見られない。値は本人が決めて **Cloudflare の Worker → Settings → Variables and Secrets** に入れる（AI には言わない）。
- URL に鍵を付ける方式は簡易版。人に見せる画面になったら Cloudflare Access など別の認証に替える。
