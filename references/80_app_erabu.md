# 80 何を作るか・誰に・いくらで（タスク4）

**先に商品を決める。** 決まらないと Stripe の商品・ページの文・保存する項目が決まらない。

## 本人に聞く5つ（答えを `state/PRODUCT.md` に書く）
1. **誰に**（例：近所の◯◯に困っている人／自分の店のお客さん）
2. **何を**（例：30分の相談／PDF の資料／予約の枠／1回の作業）
3. **いくらで**（税込・一つの価格・**一回限り**。継続課金はこのキットの範囲外）
   あわせて確認：その商品は許認可が要らないか（医療・金融・酒・古物など）／Stripe の禁止業種でないか（公式の一覧を本人が見る）
4. **買った人に渡す物**（メールで送る／日時を決めて会う／URL で見せる）
5. **買う前に集める情報**（名前・メール・希望日時・自由記入 のどれか）

## ひな形で作れる3つの型（templates/app は全部これで作れる）
| 型 | 画面 | 保存する物 | 支払い |
|---|---|---|---|
| ① 申込＋支払い（デジタル商品・相談） | トップ／申込フォーム／支払いボタン／thanks | 名前・メール・メモ | 支払いリンク |
| ② 予約の申込（本人が確定） | トップ／希望日時フォーム／thanks | 名前・連絡先・希望日時×2 | 本人が確定してから支払いリンクを送る（不成立なら返金の手間がない） |
| ③ 待ちリスト（先に登録を集める） | トップ／メール登録／thanks | メール | なし（タスク6・7 は対象外） |

②の「本人が確定」= 二重予約を機械で防がない代わりに、本人が `/admin` で見て返事する。空き枠の管理まで要る時は次の段階。

## ひな形の置き場と直し方
- 土台：`templates/app/`（Cloudflare Workers ＋ D1 ＋ 静的ページ）。
- アプリは **`templates/app/` の中で育てる**（移さない）。Cloudflare の Root directory は `templates/app` のまま固定。
- 直す場所は3つだけ：
  - `src/pages.js`：文面（トップ・フォームの項目・特商法・利用条件・プライバシー・thanks）
  - `src/index.js`：`STRIPE_LINK`・フォームの項目名・保存する列
  - 列を足す時：`migrations/0002_<名前>.sql` を**新しく作り**、本人が D1 の Console で実行してからコードを push（0001 は直さない。作成済みの DB には効かない）
- 直したら commit → push（B は PR）→ Cloudflare のビルド成功を確かめて本番。

## 作ってはいけない物（このキットの範囲外）
- 外部の AI API を呼ぶ機能（Claude/ChatGPT の契約ではアプリの裏側から呼べない。別契約の API 鍵が要る）
- 継続課金・会員制（解約・未払い・権限停止の管理が要る）
- 他人の写真・文章・ロゴの転載
- 人の健康・お金の効果をうたう文（薬機法・景表法）

## 終わりの確かめ方（タスク4）
`state/PRODUCT.md` に5つの答えがあり、本人が「これでいい」と言った → 完了。
