## 入れるドメイン（1行1つ）
```
raw.githubusercontent.com
*.workers.dev
```
1行目＝キットの取り込み先（GitHub）、2行目＝公開 URL の確認用。折り返して2行に見えても1行。

## リポを選ぶ
02 の **「リポジトリ」** → 一覧から自分のリポ（例 `my-shop`）。出てこない時は「GitHub を接続」→ GitHub の画面で **Only select repositories** → そのリポ → **Install & Authorize**（本人の操作）。

## 最初の一言（そのまま貼る）
```
このキットを読んで始めて： https://github.com/homepagecompany1-cmd/sugukuru-kit-free
```
合格の目安：「A（Claude）で進めます」→ 取り込み → push → **残りのタスクの表** → タスク1の案内が1つ。

## よくある詰まり
| 見えた物 | 答え |
|---|---|
| Code タブが無い | 候補：プラン（Pro/Max/Ultra/Team）に含まれていない／アプリが古い／ログイン中のアカウントが違う。公式の対応プランを確認。 |
| 「host not allowed」 | 05 の欄にドメインが無い。足して保存し、同じ一言をもう一度。 |
| リポが一覧に出ない | GitHub 接続でそのリポを選んでいない。03 ではなく「リポジトリ」側。 |
| 「変更を保存」が2回要る | 05 で1回、04 で1回。04 を閉じると消える。 |
| 英語の案内（Fable 5.2 など） | 閉じてよい。モデルは初期値のまま。 |
| ログインが戻らない | Safari か Chrome で開く。アプリ内ブラウザは不可。 |
